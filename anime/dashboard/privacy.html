Privacy Policy

Calm Haven Upload is a private automation tool used only by its owner to upload videos to the owner’s own YouTube channels via the YouTube Data API.

What data is accessed: only the owner’s own YouTube channels (channel name, uploading videos, thumbnails and playlists). No data from other users is requested, collected, stored, sold or shared.

Storage: access tokens are stored encrypted as GitHub Actions secrets and are used only to perform uploads. Access can be revoked at any time at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
